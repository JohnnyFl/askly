# Askly

Ask questions about a YouTube channel and get answers drawn from its video transcripts, without watching hours of video.

**Live (frontend):** https://askly-pi.vercel.app/channels

## Architecture
- **Backend:** ~18 AWS Lambda functions in Go behind API Gateway — auth, channels, transcriptions, chat messages, subscriptions.
- **RAG:** transcripts are split into chunks (`chunking_service.go`), embedded with Amazon Titan Embeddings v2 on Bedrock, searched by an in-memory vector index (`vector_search.go`); the answer is generated by Claude on Amazon Bedrock.
- **Auth and roles:** JWT authorizer, admin/user roles, usage limits per plan.
- **Billing:** Paddle subscriptions and webhooks.
- **Storage:** DynamoDB (users, channels, messages, subscriptions), S3, Cognito.
- **Infrastructure as code:** Pulumi (Go) in `infra/`.
- **Frontend:** Next.js 13 (App Router), TypeScript, Tailwind, shadcn/ui.

## Stack
Go · AWS Lambda · API Gateway · DynamoDB · S3 · Cognito · Amazon Bedrock (Claude, Titan) · Pulumi · Paddle · Next.js

## Build and deploy
```bash
make build-lambdas   # compile the Go Lambdas
make deploy          # pulumi up
make seed            # seed initial data
```

## Limits
The vector index is in memory (fine for a few channels; a managed vector store would be the next step). The deployed backend is off, so the live site shows the UI only.
